BEWEGEN => MOVING AROUND
  Pijltoetsen ...... cel voor cel          Tab .. cel naar rechts =>   Arrow keys ....... cell by cell           Tab .. cell to the right
  PgUp / PgDn ...... scherm omhoog/omlaag =>   PgUp / PgDn ...... screen up/down
  Home / End ....... eerste / laatste gevulde kolom van deze rij =>   Home / End ....... first / last filled column of this row
  F5 / Ctrl+G ...... ga naar cel, bv. B12 of Kosten!A1 =>   F5 / Ctrl+G ...... go to cell, e.g. B12 or Kosten!A1
  F6 / F7 .......... volgend / vorig tabblad =>   F6 / F7 .......... next / previous sheet
INVOEREN => ENTERING DATA
  Gewoon typen ..... begint meteen met invoeren in de cursorcel =>   Just typing ...... starts entering straight into the cursor cell
  Enter / F2 ....... de huidige cel bewerken =>   Enter / F2 ....... edit the current cell
  Del / Backspace .. cel wissen =>   Del / Backspace .. clear cell
  Een getal wordt een getal, = + of @ vooraf maakt een formule, =>   A number becomes a number, a leading = + or @ makes a formula,
  al het andere is tekst. Een apostrof dwingt tekst af: '007 =>   everything else is text. An apostrophe forces text: '007
FORMULES => FORMULAS
  Rekenen .......... + - * / ^ en haakjes, bv. =(A1+A2)*1.21 =>   Arithmetic ....... + - * / ^ and brackets, e.g. =(A1+A2)*1.21
  Vergelijken ...... = <> < > <= >= geven 1 (waar) of 0 (onwaar) =>   Comparing ........ = <> < > <= >= give 1 (true) or 0 (false)
  Verwijzen ........ A1   $A$1 blijft staan bij kopieren =>   References ....... A1   $A$1 stays put when copying
                     Kosten!B3 wijst naar een ander tabblad =>                      Kosten!B3 points at another sheet
  Bereik ........... A1:B10  (ook A1..B10 mag) =>   Range ............ A1:B10  (A1..B10 works too)
  Over bereiken .... SOM GEM MIN MAX AANTAL =>   Over ranges ...... SOM GEM MIN MAX AANTAL
  Over getallen .... ABS INT WORTEL AFROND(x;n) REST(x;y) MACHT(x;y) =>   Over numbers ..... ABS INT WORTEL AFROND(x;n) REST(x;y) MACHT(x;y)
                     EXP LN LOG SIN COS TAN PI() =>                      EXP LN LOG SIN COS TAN PI()
  Kiezen ........... ALS(voorwaarde;dan;anders) =>   Choosing ......... ALS(condition;then;else)
  Argumenten scheiden met ; of , ; de decimale punt is een punt. =>   Separate arguments with ; or , ; the decimal separator is a point.
  Fouten: #DEEL/0 #NAAM? #SYNTAX #KRING! #VERW! #GETAL! #ARG! #DIEP! =>   Errors: #DEEL/0 #NAAM? #SYNTAX #KRING! #VERW! #GETAL! #ARG! #DIEP!

  Ctrl+V ........... plakken; vraagt waar. Verwijzingen schuiven =>   Ctrl+V ........... paste; asks where. References shift along,
